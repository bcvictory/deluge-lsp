# Deluge Language Server

Language server and VS Code-compatible extension for Zoho Deluge scripts.

It provides completions, hover documentation, diagnostics, signature help, document symbols, formatting, snippets, grammar support, and a bundled dark theme for `.dg`, `.ds`, and `.deluge` files.

## Features

- Deluge keyword, function, and type-method completions.
- `zoho.*` service completions, including CRM-focused method metadata.
- Hover docs for Deluge functions, keywords, type methods, and CRM API URLs.
- Signature help for Deluge functions.
- Document symbols for functions and common block structure.
- Basic formatting for indentation normalization.
- Diagnostics for common Deluge mistakes:
  - unmatched braces and parentheses
  - missing semicolons
  - multiple statements on one line
  - smart quotes and Unicode semicolon lookalikes
  - COQL `LIMIT` values above 200
  - `zoho.crm.createRecord` / `zoho.crm.updateRecord` calls missing an options map

## CRM API Intelligence

The language server includes `data/crm-endpoints.json`, a compact endpoint catalog extracted from the Zoho CRM REST API collection and enriched with Deluge examples.

Current CRM-aware behavior includes:

- `invokeurl` URL completions for common CRM API endpoints.
- HTTP method completions on `type:` lines.
- Connection-name suggestions on `connection:` lines.
- Hover documentation for CRM API URL strings.
- Enriched `zoho.crm.*` completions and hover text with parameters, return shapes, examples, errors, and gotchas.

For CRM write helpers, the diagnostics intentionally warn when `createRecord` or `updateRecord` omits the `optionsMap` parameter. Zoho defaults can still run approval, blueprint, and orchestration scripts. To suppress trigger scripts, pass an options map whose `trigger` key is an empty List.

```deluge
dataMap = Map();
dataMap.put("Stage", "Job Created");

triggerList = List();
optionsMap = Map();
optionsMap.put("trigger", triggerList);

resp = zoho.crm.updateRecord("Deals", dealId, dataMap, optionsMap);
info resp;
```

## Install From Source

```bash
git clone https://github.com/bcvictory/deluge-lsp.git
cd deluge-lsp
npm install
npm run compile
```

## VS Code / Cursor Extension

Build a local VSIX:

```bash
npx @vscode/vsce package --no-dependencies
```

Install into VS Code:

```bash
code --install-extension deluge-lsp-*.vsix --force
```

Install into Cursor:

```bash
cursor --install-extension deluge-lsp-*.vsix --force
```

After installation, open a `.dg`, `.ds`, or `.deluge` file. The extension activates on the `deluge` language.

## Generic LSP Client

Compile first:

```bash
npm run compile
```

Then configure your LSP client to run:

```bash
node /absolute/path/to/deluge-lsp/out/server.js --stdio
```

Map these extensions to the `deluge` language:

```json
{
  ".dg": "deluge",
  ".ds": "deluge",
  ".deluge": "deluge"
}
```

## Development

```bash
npm install
npm run compile
```

Watch TypeScript while editing:

```bash
npm run watch
```

Validate one Deluge file from the command line:

```bash
npm run compile
node scripts/validate-file.js /path/to/file.dg
```

Generated files such as `out/`, source maps, `node_modules/`, and packaged `.vsix` files are intentionally ignored by git.

## Regenerate CRM Endpoint Data

The CRM endpoint catalog is generated by:

```bash
python3 scripts/extract-crm-endpoints.py
npm run compile
```

The script expects a local export of the Zoho CRM REST API Postman collection. Adjust the collection path in the script if your file is elsewhere.

## Notes

Diagnostics are intentionally conservative. Deluge syntax is flexible, and some checks are heuristic, especially for multi-line calls and continuation-heavy expressions.

The language server is designed for practical editing assistance, not as a full Deluge compiler.
